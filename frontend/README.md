# Postal Intelligence Web App

Six-section judge-ready prototype for the AI-Powered Delivery Post Office Identification System.

## Run

```powershell
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000`.

The frontend is a local prototype simulation. The sandbox, confidence sliders, language tabs, theme toggle, judge navigation, print/PDF summary, and QR placeholder do not claim live model accuracy or government deployment results.
